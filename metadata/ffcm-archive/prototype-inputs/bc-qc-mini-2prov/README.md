# BC + QC Two-Province Diagnostic Fixture

This fixture is generated by `fresh_fibre.bc_qc_mini_2prov` from the
`bc-mini` base fixture plus QC synthetic-bounded mini cells under
`qc-diagnostic/`. It merges BC supply (SCANFI diagnostic mini path)
with QC supply (CASFRI v5 / QC IEQM translation path) into a single
unified `supply_offer.csv`, eleven cells of network / technology /
transport / market tables (BC + QC), one LP round with a
province-keyed solution summary, and an inter-provincial pathway
flow comparison file.

The fixture is **synthetic-bounded**. No raw provincial payloads live
in this directory. Real BC VRI / SCANFI inputs are archived in the
`data/` submodule; real QC IEQM inputs are archived at
`data/raw/qc_inventory/2023-ieqm-eighth/`. The adapter reads only the
published CASFRI v5 translation tables under
`data/raw/casfri_v5/translation_tables/`.

## Generation

```bash
.venv/bin/python -m fresh_fibre.bc_qc_mini_2prov \
  --workdir metadata/ffcm-archive/prototype-inputs/bc-qc-mini-2prov
```

The runner rebuilds the fixture, runs the BC supply chain
(SCANFI mini path), runs the QC supply chain (`qc_ws3_export` bridge
through `casfri_qc_reader`), merges to a unified `supply_offer.csv`,
rebuilds `graph_*`, runs the LP, and emits the comparison artefacts.

## Status

The fixture is **diagnostic only**. The BC yield rules remain
synthetic placeholders (Path P3.4); the QC yield rules are documented
in `qc-diagnostic/qc_diagnostic_yield_rules.csv` as
`qc_residue_policy_unresolved`. Cost surfaces remain
`qc_supply_cost_not_calibrated`. The fixture's purpose is to prove the
inter-provincial LP machinery is operational; it is **not** a
calibration channel and is **not** production-ready.
