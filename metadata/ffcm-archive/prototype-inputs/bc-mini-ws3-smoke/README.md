# BC Mini-Network ws3 Smoke Variant

This directory is generated by `fresh_fibre.ws3_variant` from the base
`bc-mini` fixture. It replaces `supply_offer.csv` with the supply-offer export
from the local real ws3 smoke run while keeping the downstream BC mini network,
technology, transport, and market tables unchanged.

The variant is diagnostic only. It proves that real ws3 harvest-output rows can
feed the existing downstream LP path, but the ws3-to-FRESH spatial crosswalk,
costs, and facility/market assumptions are not production inputs.
